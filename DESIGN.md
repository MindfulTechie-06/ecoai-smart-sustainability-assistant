# Echo AI Design Specification & System

## Brand Identity
Echo AI is a premium, minimalist climate-tech SaaS platform.
Headline: "Make Every Sustainability Decision Count."
Description: "Echo AI transforms everyday resource data into intelligent insights, predictive simulations and practical sustainability actions."
Central USP: "From fragmented resource data to intelligent, measurable sustainability action."

## Core Color Palette
- Primary Green: `#247A55` (CTA buttons, active badges, primary accents)
- Sage Green: `#A7C9AF` (Secondary borders, subtle illustrations, chart series)
- Mint Accent: `#DDF3E5` (Chip fills, highlight backgrounds, hover states)
- Pure Surface: `#FFFFFF` (Card surfaces, clean modals)
- Warm Off-White Canvas: `#FBFBF9` / `#F6F8F6` (App workspace and landing background)
- Deep Text: `#17251E` (Headlines, body high-contrast text)
- Muted Slate-Green Text: `#66756B` (Secondary descriptions, axis labels, metadata)
- Soft Border: `#E6ECE7` (Structural dividers, card borders)

## Elevation & Cards
- Crisp 1px borders in `#E6ECE7` with soft diffused ambient shadows: `box-shadow: 0 1px 3px rgba(23, 37, 30, 0.04), 0 6px 16px rgba(23, 37, 30, 0.02)`.
- Hover state: `transform: translateY(-2px); box-shadow: 0 4px 20px rgba(36, 122, 85, 0.08); border-color: #A7C9AF;`.

## Five Core Indicators
1. Carbon Emissions (tCO₂e / kg CO₂e) - Color: `#247A55`
2. Energy Consumption (MWh / kWh) - Color: `#D97706` (Warm amber)
3. Water Consumption (kL / L) - Color: `#0284C7` (Clean azure)
4. Waste Generation (Tonnes / kg) - Color: `#7C3AED` (Violet slate)
5. Mobility Emissions (tCO₂e from commuting/fleet) - Color: `#059669` (Emerald teal)
